# ETutoring: Enterprise Educational Management Platform

This repository hosts the source code for ETutoring, a comprehensive, decoupled full-stack platform engineered to digitalize and optimize the operational workflows of online education. The system provides a centralized ecosystem for managing complex interactions between administrative staff, educational tutors, and students.

## System Architecture

The application implements a strict separation of concerns through a modular architecture:
* **Front-end/**: A high-performance, single-page application (SPA) built with modern JavaScript frameworks, focusing on complex data visualization and interactive scheduling components.
* **Back-end/**: A robust RESTful API infrastructure designed to handle secure data persistence, complex querying logic, and centralized business rules.

## Core Technical Features

Development efforts were heavily concentrated on solving complex logistical challenges within the educational domain, specifically:
* **Advanced Scheduling System:** Implementation of an interactive Meeting Calendar that accurately maps tutor availability against student requests, handling edge cases in time management and session conflicts.
* **Interactive Data Visualization:** Development of dynamic Timeline UIs to track educational progress, session histories, and upcoming milestones with high rendering performance.
* **Scalable Data APIs:** Engineering optimized backend endpoints, such as the Tutor Listing API, capable of executing complex filtering and search algorithms efficiently.
* **Role-Based Workflows:** Secure, distinct dashboard environments tailored for specific user operational privileges.

To explore the codebase or deploy the system locally, refer to the detailed technical documentation provided within the respective `Front-end` and `Back-end` directories.
